# Redesign direction

Audience: overseas recovered-paper suppliers and Indian paper-mill procurement teams.
Mode: marketing / industrial, with a single immersive material scene.
Thesis: the physical transformation of paper is the identity, while trade information stays direct and readable.
Dials: design variance 8, motion intensity 7, content density 4.

Keep: original company name, forest-green identity, all 15 grades, sourcing regions, contact details, quality criteria, supplier checklist, navigation labels/anchors, SEO metadata.
Retire: italic serif headline endings, section-number labels, decorative coordinates, repeated rule-separated lists, generic inspection dashboard, blanket fade-up animation, repeated full-section compositions.

Palette: forest #073d2b; dark green #032c20; paper white #f4f6f1; lime accent #c6dc9d; kraft #c0a886; ink #193d2c.
Type: Manrope variable, strong 650-800 display and 450-550 body. No serif accents. Sentence-case content; oversized type reserved for opening and manifesto.
Shape: small 4px controls; larger rounded clipping only where it describes folded material.
Layout: large typographic hero with 3D paper layered into the composition; compact company introduction; scroll-driven material journey; an interactive grade index and material specimen; geographic sourcing map; grouped procurement details; progressive manifesto; supplier checklist and direct contact.

Hero:
[company name                 navigation / supplier]
[Paper                  sculptural paper loop      ]
[in motion.                   extends behind type ]
[From global sources to Indian paper mills.        ]
[products / supplier                              ]

Motion: WebGL represents reuse through a continuous layered paper loop; responds to pointer input and scroll, pauses offscreen, with a visible pause control and static fallback. Journey images change with actual process stage. Product selection morphs the material preview. React Bits ScrollReveal adapted with scoped cleanup and reduced-motion support. Trade routes draw from region selection. No scroll hijacking.

Review: avoids the previous generic cream/serif/border system. Green and paper photography remain because they are explicit brand/content requirements. Contrasting sourcing/contact sections also remain because the user specifically requested them. Do not add unrelated skills, cookie banners, fabricated data, or API features.

Skill sources: attached frontend-design-studio, frontend-design-context, design-taste-frontend-attached; Leonxlnx redesign-existing-projects. Attached SDK, documentation and skill-authoring documents are installed but irrelevant to site implementation. Some attachments reference scripts not supplied; those resources are not invented or required for this implementation.
